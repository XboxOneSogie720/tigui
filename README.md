# tigui
A graph-based GUI library for the TI-84 Plus CE.

## Features
- Fully stack driven under the hood
- Supports all kinds of shapes and UI elements
- Consistent screen element definitions

## How to Build
1. Grab yourself the [toolchain](https://ce-programming.github.io/toolchain/)
2. Clone this repository: `git clone https://www.github.com/XboxOneSogie720/tigui.git`
3. copy the source files into your project
4. Use them
